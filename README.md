# CCRegister — Child Care Registration SaaS

CCRegister is a planned multi-tenant child care registration platform for operators and guardians in Canada and the United States.

## Project status

Requirements documentation initialized October 9, 2026. This repository does **not yet** contain a working application or the ChatGPT Work prototype source files.

## Main workflows

- Administrative setup of registration forms and programs
- Guardian completion of registration data
- Program age groups and separately named classrooms
- Custom schedules including full day, morning, afternoon, before-school, and after-school care
- Four-week custom scheduling grid
- Capacity and occupancy tracking by AM/PM segments and optional before-/after-school sections
- Compact administrative capacity dashboard and detailed drilldowns
- View and print completed registration forms as PDFs

See `docs/PRODUCT_REQUIREMENTS.md` for additional design decisions.
